# Hero Industries (umbrella page) - image kit

Upload the contents of `images/` to the `genesisjoaia/web-images` repo,
in a folder for this hero (suggested name: `Industries`).

| File | Use | Size |
|---|---|---|
| hotel.jpg | Scene 1, hotel reception | 840 x 1200 |
| event.jpg | Scene 2, installation | 840 x 1200 |
| scenic.jpg | Scene 3, train window | 840 x 1200 |
| avatar.png | Guide avatar, all three replies | 160 x 160 |

Photos are cropped to the card format (390 x 557 at 2x). Corners and shadows
are added in CSS, so the files are square.
